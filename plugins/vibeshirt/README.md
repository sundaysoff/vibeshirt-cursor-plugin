# VibeShirt for Cursor

Design custom t-shirts from Cursor's agent: generate art or upload your own, edit layers, preview mockups, get volume pricing and check out through Shopify.

Connects to the hosted VibeShirt MCP server at `https://vibeshirt.com/api/connector/mcp` (OAuth sign-in on first use). Setup docs: https://vibeshirt.com/connect
